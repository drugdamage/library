Open a terminal in the project folder. Requires Python 3.10+.

First run:
python -m venv .venv
Use python3 if python is unavailable.

Activate the environment:
macOS/Linux: source .venv/bin/activate
Windows PowerShell: .\.venv\Scripts\Activate.ps1

Install and start:
pip install -r requirements.txt
python main.py

For later runs, activate the environment and run python main.py.

Demo logins: admin / 1234, lib / 1111.
library.db is created automatically. Keep it to preserve your data.
